How to Calculate Percentage Increase

Percentage increase (or decrease) measures how much a value has changed relative to its original amount. The formula works for any two numbers:

Percentage Change = ((New Value − Original Value) / |Original Value|) × 100

If the result is positive, the value increased. If the result is negative, the value decreased. The absolute value of the original is used in the denominator to handle negative starting values correctly.

Percentage Increase Formula

To break it down step by step:

  1. Subtract the original value from the new value to find the absolute difference.
  2. Divide the difference by the absolute value of the original.
  3. Multiply by 100 to convert the decimal to a percentage.

For example, if a product's price goes from $80 to $100:

(100 − 80) / 80 × 100 = 25% The price increased by 25%.

If the same product later drops from $100 to $90:

(90 − 100) / 100 × 100 = −10% The price decreased by 10%.

Frequently Asked Questions

What is the difference between percentage increase and percentage points?

Percentage increase measures relative change (e.g., a rate going from 5% to 10% is a 100% increase). Percentage points measure the absolute difference between two percentages (the same change is 5 percentage points). Confusing the two is one of the most common statistical mistakes.

Can the percentage increase be more than 100%?

Yes. If the new value is more than double the original, the percentage increase exceeds 100%. For example, going from 50 to 150 is a 200% increase.

How do I calculate percentage decrease?

Use the same formula. When the new value is smaller than the original, the result will automatically be negative, indicating a decrease. This calculator handles both directions and labels the result accordingly.
